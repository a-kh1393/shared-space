# فضای مشترک — پروژهٔ اندروید

یک برنامهٔ اندروید کوچک (WebView) که همان «فضای مشترک» را داخل خودش اجرا می‌کند و بدون اینترنت کار می‌کند.
حداقل نسخهٔ اندروید: ۱۰.

## گرفتن APK بدون نصب چیزی روی کامپیوتر
1. در github.com یک مخزن (repository) تازه بسازید.
2. همهٔ محتویات همین پوشه را در آن آپلود کنید (پوشهٔ مخفی `.github` هم باید برود).
3. به تب **Actions** بروید؛ ساخت خودکار شروع می‌شود (حدود ۳–۵ دقیقه). اگر شروع نشد، «Build APK» ← «Run workflow».
4. وقتی سبز شد، وارد همان اجرا شوید و از پایین صفحه **shared-space-apk** را دانلود کنید؛ داخلش `app-debug.apk` است.
5. APK را روی گوشی بیاورید و نصب کنید (اجازهٔ «نصب از منبع ناشناس» را بدهید).

## یا با Android Studio
پوشه را با Android Studio باز کنید و **Build ← Build APK(s)** را بزنید.
